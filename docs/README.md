# Конференции.РФ

Информационная система для бронирования помещений для проведения Всероссийских конференций.

## Стек технологий
- **Backend:** Node.js, Express.js
- **База данных:** SQLite (better-sqlite3)
- **Шаблонизатор:** EJS
- **Фронтенд:** Bootstrap 5.3 (локально), HTML, CSS
- **Аутентификация:** express-session, bcryptjs

## Установка и запуск

1. Установите зависимости:
   ```bash
   npm install
2. Запустите сервер:
bash
npm start

Безопасность
Пароли хэшируются с помощью bcryptjs перед сохранением в БД.

Сессии хранятся на сервере, cookie имеют флаги httpOnly и sameSite: 'lax'.

Время жизни сессии: 2 часа, автоматический выход после 20 минут бездействия.

Доступ к защищенным маршрутам контролируется мидлварами requireAuth и requireAdmin.
