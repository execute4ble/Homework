Данные хранятся в массиве JS-объектов `applications`, который сериализуется
в `localStorage` под ключом `admin_applications`. Каждая заявка имеет вид:

```js
{
    id: 1,
    user: 'Иванов Иван Иванович',
    room: 'Конференц-зал «Альфа»',
    date: '15.10.2025',
    payment: 'Очное посещение',
    status: 'Новая'
}
При первом запуске (если localStorage пуст) массив инициализируется
демонстрационными данными из DEMO_APPLICATIONS. Любое изменение
(смена статуса) сразу вызывает saveApplications(), что исключает потерю
данных при перезагрузке страницы.

2. Смена статуса заявки
Реализована через выпадающий список (<select>) в колонке «Действия»
(Вариант А из ТЗ). Поток:

Пользователь меняет значение <select>.

Обработчик change на <tbody> (делегирование) ловит событие.

Открывается модальное окно подтверждения с текстом
«Изменить статус заявки №X с «А» на «Б»?».

При подтверждении вызывается changeStatus(id, newStatus):

обновляется поле status в объекте;

массив сохраняется в localStorage;

вызывается renderAll() — перерисовка таблицы и счётчиков;

строка подсвечивается зелёным (row-flash);

выводится toast-уведомление.

Если пользователь отменяет — значение <select> откатывается к исходному.

3. Фильтрация и поиск
Фильтр по статусу — табы nav-pills («Все», «Новая»,
«Мероприятие назначено», «Завершено»). Рядом с каждым табом — бейдж
со счётчиком (renderCounters()).

Поиск — поле #searchInput, фильтрует одновременно по user
и room (регистронезависимо).

Сортировка — клик по заголовку колонки. Стрелка ▲/▼ показывает
направление. Для даты выполняется преобразование ДД.ММ.ГГГГ → Date.

Все три параметра хранятся в глобальном состоянии (currentFilter,
currentSearch, sortField, sortDirection) и применяются
в getFilteredApplications().

4. Пагинация
По 10 заявок на страницу (константа PAGE_SIZE). Функция
renderPagination() динамически строит кнопки «‹ 1 2 3 … ›». При смене
фильтра или поиска currentPage сбрасывается в 1.

6. Возникшие сложности и их решения
Проблема	Решение
При смене <select> он не должен «залипать» на новом значении до подтверждения	Откат select.value = oldStatus сразу после открытия модалки
Накопление обработчиков на кнопке подтверждения модалки	Клонирование кнопки (cloneNode) перед навешиванием нового click
Сортировка даты «ДД.ММ.ГГГГ» как строки работает неверно	Преобразование в Date в компараторе sort()
XSS при выводе ФИО / помещения	Функция escapeHtml() для всех текстовых полей
Кодировка русского текста в CSV при открытии в Excel	Добавлен BOM \uFEFF + разделитель ;
